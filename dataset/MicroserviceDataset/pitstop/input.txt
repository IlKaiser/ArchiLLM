# SYSTEM DESCRIPTION:
Pitstop is a comprehensive garage management system designed as a microservices-based sample application that demonstrates modern software architecture patterns and containerization technologies. The system serves garage operators, mechanics, and administrative staff by managing customers, vehicles, workshop operations, maintenance jobs, invoicing, and notifications in a fictitious car repair shop environment. Built with .NET and leveraging technologies like Docker, Kubernetes, RabbitMQ for messaging, SQL Server for data persistence, and optional service mesh implementations (Istio/Linkerd), Pitstop showcases enterprise-grade patterns including CQRS, event-driven architecture, event sourcing, Domain Driven Design, and eventual consistency across distributed services.
