# SYSTEM DESCRIPTION:
EnterprisePlanner is a distributed microservices-based enterprise resource planning system designed to manage customer relationships, order processing, and shipment tracking for businesses. The system follows a microservices architecture with separate services for customers, orders, and shipments, all orchestrated through an API Gateway and supported by JWT-based authentication and RabbitMQ messaging for inter-service communication. The platform serves business users who need to manage customer data, process orders, and track shipments through a modern Angular web application that provides intuitive interfaces for data entry, editing, and reporting. The system is containerized using Docker and includes comprehensive pagination, filtering, and validation capabilities to handle enterprise-scale data volumes efficiently.
