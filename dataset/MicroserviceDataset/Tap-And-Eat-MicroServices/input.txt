# SYSTEM DESCRIPTION:
Tap-And-Eat-MicroServices is a distributed microservice architecture platform designed for restaurant and retail store management. The system provides a comprehensive set of services for handling restaurant operations including account management, customer data, inventory items, pricing, store information, and food tray ordering functionality. Built using Spring Boot and Java 8, the platform features a centralized configuration service and automatic service discovery, enabling scalable deployment through Docker containers. The architecture supports restaurant staff, customers, and administrators who need to manage various aspects of food service operations from menu items and pricing to customer accounts and order processing.
