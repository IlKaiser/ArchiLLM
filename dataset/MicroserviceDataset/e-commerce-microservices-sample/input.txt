# SYSTEM DESCRIPTION:
This is a sample e-commerce application built using a microservices architecture and cloud-native patterns, demonstrating modern software engineering practices. The system consists of five independently deployable microservices: a Product Catalog service (Node.js/MongoDB), a Shopping Cart service (Java Spring Boot/Redis), a User Profile service (Python FastAPI/PostgreSQL), a Search service (Node.js/Elasticsearch), and a React-based Store UI frontend. The application utilizes polyglot programming languages and databases, is containerized with Docker, and can be deployed to local Kubernetes clusters or AWS cloud infrastructure using Terraform and Kustomize configurations.
