# SYSTEM DESCRIPTION:
This is a CQRS (Command Query Responsibility Segregation) microservice demonstration system that implements a Product Master Data service using Spring Boot, Spring Cloud, and the Axon Framework. The system separates command and query responsibilities into distinct microservices, with the command-side handling product creation and modifications while the query-side manages read operations and materialized views. It serves developers and architects who want to understand microservice patterns, event sourcing, and CQRS implementation in a distributed system environment. The application includes supporting infrastructure services like service discovery (Eureka), API gateway (Zuul), external configuration management (Spring Cloud Config), and uses MongoDB for event storage and RabbitMQ for inter-service messaging.
