# SYSTEM DESCRIPTION:
The Spring PetClinic Microservices is a distributed veterinary clinic management system that demonstrates microservices architecture using Spring Cloud technologies. The system manages pet owners, their pets, veterinary visits, and veterinarian information through separate microservices including customers service, visits service, vets service, and a GenAI chatbot service. It serves veterinary clinic staff, administrators, and pet owners who need to manage appointments, track pet health records, and access veterinary services. The system is built with Spring Boot microservices orchestrated through an API Gateway, service discovery (Eureka), centralized configuration management, and includes comprehensive monitoring with Grafana, Prometheus, and distributed tracing capabilities.
