# SYSTEM DESCRIPTION:
FTGO is a microservices-based food delivery application that demonstrates enterprise-level microservice architecture patterns and serves as a reference implementation for the "Microservice Patterns" book. The system enables consumers to browse restaurants, place food orders, and track their delivery status, while allowing restaurants to manage their menus and kitchen staff to process orders. Built with Spring Boot and Java, the application implements sophisticated patterns including event sourcing, CQRS, saga-based transaction management, and API gateway routing, utilizing technologies like Apache Kafka for messaging, MySQL for data persistence, and Docker/Kubernetes for deployment orchestration.
