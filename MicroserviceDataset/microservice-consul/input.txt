# SYSTEM DESCRIPTION:
This is a microservices demonstration system that showcases a distributed e-commerce architecture using HashiCorp Consul for service discovery and Apache HTTP as a reverse proxy and load balancer. The system consists of three core Java Spring Boot microservices (Order, Customer, and Catalog) that communicate with each other to handle order processing, customer management, and product catalog operations. It serves developers and architects who want to learn about microservices patterns, service discovery, and distributed system monitoring, featuring comprehensive observability through Prometheus for metrics, Elastic Stack for logging, and Zipkin for distributed tracing. The system is fully containerized with Docker and provides multiple deployment configurations for different monitoring and observability scenarios.
