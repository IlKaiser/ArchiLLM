# SYSTEM DESCRIPTION:
This is a demonstration microservices architecture built with Spring Boot and Netflix OSS components that implements a card and statement management system. The system consists of multiple independent services including card-service for managing card data, statement-service for handling financial statements, and a card-statement-composite service that aggregates data from both services. It leverages key Netflix OSS components such as Eureka for service discovery, Zuul for API gateway routing, Spring Cloud Config for centralized configuration management, and includes monitoring capabilities through Hystrix Dashboard and Turbine for circuit breaker metrics aggregation. The architecture is containerized with Docker and includes message queuing via RabbitMQ, serving as a comprehensive example for developers learning microservices patterns and distributed system design.
