# SYSTEM DESCRIPTION:
This is a comprehensive microservices demonstration system built with Java Spring Boot and Spring Cloud technologies, designed for educational purposes as a companion to a microservices architecture book. The system implements a simple e-commerce domain with three core business microservices (Order, Customer, and Catalog) supported by infrastructure services including Eureka for service discovery, Zuul for API gateway routing, and Turbine for metrics aggregation. It demonstrates key microservices patterns such as service discovery, load balancing with Ribbon, circuit breakers with Hystrix, and consumer-driven contract testing, and can be deployed using Docker containers with orchestration via Docker Compose or Vagrant for easy setup and experimentation.
