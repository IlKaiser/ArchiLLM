# SYSTEM DESCRIPTION:
Lelylan is an open source Internet of Things (IoT) cloud platform built on a lightweight microservices architecture that enables developers to connect, monitor, and control IoT devices. The platform is both hardware-agnostic and platform-agnostic, supporting everything from ESP8266 microcontrollers to professional embedded hardware solutions, and can be deployed on public clouds, private datacenters, or hybrid environments. It serves IoT developers, hardware manufacturers, and system integrators who need a standardized, scalable solution for device management with real-time communication capabilities through MQTT, WebSockets, and RESTful APIs. The system provides comprehensive device lifecycle management, user authentication via OAuth 2.0, real-time subscriptions and notifications, and both developer tools and end-user dashboards for device and device type management.
