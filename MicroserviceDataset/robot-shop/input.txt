# SYSTEM DESCRIPTION:
Robot Shop is a demonstration e-commerce microservices application designed to showcase modern cloud-native application monitoring and observability patterns using Instana. The system serves as a sample polyglot microservices architecture that includes typical e-commerce functionality like product catalog browsing, shopping cart management, user authentication, payment processing, shipping calculations, and product ratings across multiple technology stacks including Node.js, Python, Java, and PHP. The application is specifically engineered to run on various orchestration platforms including Kubernetes, Docker Swarm, and DC/OS, with built-in support for Istio service mesh, automated scaling, and comprehensive observability through distributed tracing and monitoring.
