# SYSTEM DESCRIPTION:
Lakeside Mutual is a comprehensive microservices-based insurance application that serves as a demonstration of domain-driven design and microservice API patterns. The system provides digital insurance services to both customers and employees of a fictitious insurance company through multiple interconnected applications including customer management, policy management, and risk assessment capabilities. The architecture consists of multiple Spring Boot backend services, React and Vue.js frontend applications, and supporting infrastructure components, all designed to handle customer data, insurance policies, risk management, and real-time customer support interactions. The system demonstrates modern enterprise patterns including API-first design, event-driven messaging, and containerized deployment strategies.
