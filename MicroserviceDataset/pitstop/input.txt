# SYSTEM DESCRIPTION:
Pitstop is a microservices-based garage management system designed to demonstrate modern software architecture patterns including CQRS, event-driven architecture, event sourcing, and domain-driven design. The system serves garage operators, customers, and workshop staff by managing vehicle registrations, customer information, maintenance job scheduling, invoicing, and notifications. Built on .NET with RabbitMQ for messaging and SQL Server for data persistence, it supports deployment via Docker Compose for development and Kubernetes with optional service mesh (Istio/Linkerd) for production environments. The application includes comprehensive automated UI testing and demonstrates advanced concepts like eventual consistency across distributed services.
